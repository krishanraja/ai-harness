# The Summary and Plan

## Contents

- Amnesia-proof summary

## Amnesia-proof summary

Write for a future agent that remembers none of the conversation. Preserve facts and Krish's words rather than writing a warm recap.

```text
THE TASK
[What is being delegated, in one line]

THE REAL GOAL
[What the work is actually for; use Krish's words where available]

WHY NOW
[What changed; if nothing changed, say so]

CONSTRAINTS
[What cannot be done, must remain true, or must not be touched]

A CLEAR WIN
[An outcome concrete enough to evaluate]

WHAT IT FEELS LIKE
[Krish's words verbatim; do not tidy or paraphrase]

WHAT I ALMOST GOT WRONG
[The assumption an answer corrected; if none, say that honestly]

STILL UNKNOWN
[Each unknown, the assumption if any, and whether it blocks execution]
```

`WHAT IT FEELS LIKE` stays verbatim because paraphrasing replaces Krish's register with the agent's.

`WHAT I ALMOST GOT WRONG` is the receipt for the interview. If the work would have been approached identically without it, say so. That is evidence that a similar future task may need a shorter briefing gate.

`STILL UNKNOWN` is not a failure. A named gap can be resolved or consciously bounded; a plausible invented answer becomes an unauthorized decision.

## Plan

Propose five or six lines at most:

1. State the first executable step concretely.
2. Order the remaining stages by dependency.
3. State material assumptions left by the interview.
4. Flag expensive-to-reverse or approval-gated steps.
5. Name the observable clear-win signal that will pass to `verification-loop`.

This is a briefing plan, not a replacement for `strategy-brief`. The strategy layer operationalizes the route, authority, alternatives, and verification evidence before material execution.

## Stop condition

After a completed interview, do not start the delegated work. Wait for Krish's go or correction. The interview earned its time only if a wrong reading can still be corrected while it is a sentence rather than a deliverable.

If Krish explicitly declined further interviewing and told the agent to use judgment or proceed, that instruction is the go for work already inside the original scope. It does not waive a separate approval gate.
