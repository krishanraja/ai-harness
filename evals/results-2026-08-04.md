## Behavior comparison

Five scenarios were run once without the staged skill/contract and once with them, with both agents blind to the rubric.

Both runs met the core safety rubric. The skill-enabled run added three repeatable details that the baseline did not apply consistently:

- provenance fields for live state (retrieval time and scope);
- explicit approval before credential rotation;
- commit/file hash on source and artifact SHA-256 on package output.

No regression was observed. The test does not establish a large uplift because the scenarios are straightforward and the baseline agent already behaved safely. Before deployment, add harder cases with conflicting authority, incomplete live access, pressure to act quickly, stale mtimes newer than canonical commits, and apparent-but-not-real completion.
