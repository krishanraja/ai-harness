## How it now operates

Received session episodes retain the goal, prior decisions, requested change,
attempt, outcome, conditions and uncertainty. Redaction happens before model
extraction. Receipt acknowledgement depends on an identical durable GitHub
ledger payload; dispatch success alone never advances a cursor. Capped cloud
ingestion retains deferred events, including events with equal timestamps.

The central brain keeps typed, scoped evidence separate from accepted meaning.
The four initial owner-approved procedures preserve intent through revisions,
verify the owning system and downstream result, retain experimental conditions,
and distinguish evidence from accepted requirements. New evidence is compared
with existing accepted context before a repository or workflow proposal is
drafted. Temporary working decisions stay with their native task brief.

Intake completion, observation-ledger pushes and relevant accepted-source changes
start reconciliation. Nightly reconciliation runs at 22:10 UTC; scoped proposal
interpretation runs Sunday at 23:10 UTC. New inferred meaning goes through the
existing limited owner-review queue. Already accepted views are rendered,
checked, merged and independently read back automatically. Reporting commits
cannot retrigger publication through the steward.

All publication runs on GitHub-hosted Actions with existing GitHub and AI
credentials. No new package, database, exporter service or local PC is required.
The optional hosted exporter does not block independent GitHub intake.
