## Order

GitHub redirects an old name to the new one, never the reverse, and every writer here calls GitHub by `name`. So this change is held as a draft until Krish renames the repositories on GitHub, and is marked ready once they are renamed.

## Which part of the North Star it moves

The number is the corrections Krish gives twice in a week. A name that hides whether a repository is part of the OS, or a canon that calls an engine by a name it no longer has, invites the same correction again. One name per repository, with its former name as an alias, removes that.
